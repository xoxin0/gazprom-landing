# Лендинг «Газпром»

Одностраничный сайт в бело-голубой гамме с формой обратной связи.
Заявки уходят в Telegram-бот. Зависимостей нет — только Node.js 18+.

## Структура

```
gazprom_project/
├── index.html            # разметка лендинга
├── pages/                # страницы направлений
│   ├── naselenie.html        # газоснабжение населения
│   ├── promyshlennost.html   # промышленным клиентам
│   ├── spg.html              # СПГ и газомоторное топливо
│   └── inzhiniring.html      # инжиниринг и сервис
├── css/style.css         # стили: токены, компоненты, адаптив
├── js/main.js            # интерактив: анимации, валидация, отправка
├── assets/               # логотип
├── server/
│   ├── server.js         # HTTP: статика + /api/lead
│   ├── bot.js            # логика бота и доставка заявок
│   ├── telegram.js       # обёртка над Telegram Bot API
│   ├── lead.js           # серверная валидация заявки
│   ├── store.js          # состояние: администратор + очередь
│   ├── config.js         # чтение .env
│   └── data/state.json   # создаётся автоматически, в git не попадает
├── .env.example
└── package.json
```

## Запуск

```bash
npm start
```

Сайт откроется на http://127.0.0.1:5173

Режим с автоперезапуском при правках сервера:

```bash
npm run dev
```

## Подключение Telegram-бота

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Скопируйте `.env.example` в `.env`.
3. Вставьте токен:

```
TELEGRAM_BOT_TOKEN=1234567890:AAaBbCcDdEeFfGgHhIiJjKkLlMmNnOo
```

4. Перезапустите сервер.
5. Откройте своего бота в Telegram и отправьте `/start`.

**Первый, кто напишет боту, становится администратором.** Его Telegram ID
записывается в `server/data/state.json`, и все заявки с сайта приходят
в этот чат. Остальные пользователи получают отказ — второго администратора
бот не назначает.

Сменить администратора можно только вручную: остановить сервер, удалить
`server/data/state.json` и снова отправить боту `/start`.

## Пока токена нет

Сайт работает и без бота. Заявки проходят валидацию и складываются
в очередь в `server/data/state.json`. Как только токен будет добавлен,
а администратор — назначен, всё накопленное придёт ему одним пакетом.

## Команды бота

| Команда   | Кто может | Действие                        |
|-----------|-----------|---------------------------------|
| `/start`  | все       | назначение или проверка доступа |
| `/status` | админ     | состояние, счётчик заявок       |
| `/help`   | админ     | справка                         |

## API

| Метод | Путь           | Назначение                          |
|-------|----------------|-------------------------------------|
| POST  | `/api/lead`    | приём заявки с формы                |
| GET   | `/api/health`  | состояние сервера, бота и очереди    |

Форма защищена серверной валидацией, honeypot-полем и ограничением
в 5 заявок с одного IP за 10 минут.

## Страницы направлений

Каждая карточка блока «Чем мы занимаемся» ведёт на свою страницу в `pages/`.
Все ссылки возврата ведут на `index.html#directions`, поэтому пользователь
попадает обратно на тот же блок, а не в начало страницы.

## Деплой

Боту нужен постоянно живущий процесс: он держит long polling к Telegram.
Статический хостинг (GitHub Pages, Netlify, Vercel static) не подойдёт —
нужен сервер, который не засыпает.

Перед деплоем узнайте свой Telegram ID — он уже записан в `server/data/state.json`
после первого `/start`, либо его подскажет бот `@userinfobot`.

Обязательные переменные окружения на хостинге:

| Переменная            | Значение                          |
|-----------------------|-----------------------------------|
| `TELEGRAM_BOT_TOKEN`  | токен от @BotFather               |
| `TELEGRAM_ADMIN_ID`   | ваш Telegram ID                   |
| `NODE_ENV`            | `production`                      |

`TELEGRAM_ADMIN_ID` критичен: на хостингах диск сбрасывается при каждом деплое,
и без этой переменной файл состояния исчезнет, а место администратора займёт
первый посторонний, кто напишет боту.

### Render

1. Запушить репозиторий на GitHub.
2. Render → New → Blueprint → выбрать репозиторий (подхватит `render.yaml`).
3. Ввести `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_ID`.
4. Deploy.

Free-план засыпает после 15 минут простоя — бот в это время не принимает
сообщения. Для рабочего бота нужен платный план (в `render.yaml` указан `starter`).

### Fly.io

```bash
fly launch --no-deploy
fly secrets set TELEGRAM_BOT_TOKEN=... TELEGRAM_ADMIN_ID=...
fly deploy
```

В `fly.toml` уже выключено засыпание машины (`auto_stop_machines = false`).

### Свой сервер

```bash
docker build -t gazprom-landing .
docker run -d --restart unless-stopped -p 80:8080 \
  -e TELEGRAM_BOT_TOKEN=... -e TELEGRAM_ADMIN_ID=... \
  -v gazprom-data:/app/server/data gazprom-landing
```

Том `gazprom-data` сохраняет очередь заявок и счётчик между перезапусками.
